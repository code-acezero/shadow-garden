# Rule: Never Use Sparkle Icons

## Directive
- **NEVER use sparkle icons** (e.g. `Sparkles`, `Sparkle`, or star-burst sparkle elements from `lucide-react` or similar icon packages).
- Replace them with clean, context-appropriate icons such as:
  - For Characters / Cast: `User`, `Users`, or `Tv`
  - For AI / Assistant / Features: `Bot`, `Zap`, `Flame`, or `Cpu`
  - For Highlights / Special: `Flame`, `Star`, `Crown`, or `Compass`
  - For Dubs / Categories: `Globe`, `Languages`, or `Mic`
- Sparkle icons are strictly prohibited across all UI components, buttons, badges, modals, and overlays.
