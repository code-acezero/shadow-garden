# Rule: Never Use Sparkle Icons & Avoid Duplicate Icons

## Directives
1. **NEVER use sparkle icons** (e.g. `Sparkles`, `Sparkle` from `lucide-react` or similar icon packages).
2. **Replace them with clean, context-appropriate icons**:
   - Genres / Tags / Categories: `Tag`, `Layers`, `Shapes`
   - Cast / Characters / Creators: `Users`, `User`, `Tv`
   - AI / Assistant / Features: `Bot`, `Zap`, `Flame`, `Cpu`
   - Highlights / Specials: `Flame`, `Star`, `Crown`, `Compass`
   - Recently Added: `PlusCircle`, `CalendarPlus`
   - Best Match / Recommended: `BadgeCheck`, `ThumbsUp`
   - Dubs / Categories: `Globe`, `Languages`, `Mic2`
3. **Never duplicate the same icon for two different options**:
   - In any menu, dropdown, or list of options, each option must have its own unique and suitable icon. Do not reuse `Clock` or `Flame` across multiple different options in the same list.
