# Rule: Never Use Breathing Dots

## Directive
- **NEVER use breathing or pulsing indicator dots** (e.g. `<span className="... rounded-full animate-pulse" />` or `animate-ping` dots).
- Do not place pulsing colored circles next to title counters, status labels, or live indicators.
- Use clean typography (e.g. `24+ titles available`), static subtle badges, or crisp static icons (`CheckCircle`, `Tag`, etc.) instead.
